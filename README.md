# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Типы данных
В приложении используются типизированные интерфейсы данных, описывающие сущности веб-ларька. Все интерфейсы находятся в файле `src/types/index.ts`.

#### Интерфейс Iproduct 
Интерфейс используется для описания данных в классе Catalog

Интерфейс:
  `id: string;` - уникальный номер товара, является строкой
  `description: string;` - описание товара, является строкой
  `image: string;` - картинка товара, является ссылкой соотвествено тип является строкой
  `title: string;` - название товара, является строкой
  `category: string;` - категория товара, является строкой
  `price: number | null;` - цена товара, может быть, а может и не быть, соответственно тип либо number, либо null

#### Интерфейс IBuyer
Интерфейс используется для описания данных в классе Buyer

Интерфейс:
  `payment: TPayment;` - выбиравется тип оплаты может быть либо "online" | "offline"
  `email: string;` - адрес электронной почты покупателя
  `phone: string;` -  номер телефона покупателя
  `address: string;` - адрес покупателя

#### Интерфейс IApi
Назначение: предоставляет методы для работы с сервером, получения и отправки данных. 

Методы:
`get<T>(uri: string): Promise<T>`
  Параметр `url: string` - энд поинт get запроса, возвращает промис с объектом данных типа T.
`post<T>(uri: string, data: object, method?: ApiPostMethods): Promise<T>`
  Параметры:
  `url: string` - адрес эндпоинта
  `data: object` - данные для отправки
  `method?: ApiPostMethods` - метод запроса(типа `POST | PUT | DELETE`)
  Возвращает: Promise<T> - промис с объектом типа Т
  
### Классы слоя "Модели"

#### Класс Catalog
Содержит в себе товары, доступные для покупки.

Конструктор: 
`constructor(allProducts: IProduct[], currentProduct: IProduct)` - В конструкторе передается массив всех товаров и выбранный товар.

Поля класса:
`allProducts: IProduct[]` - хранит массив всех товаров.
`currentProduct: IProduct` - хранит выбранный товар, для подробного отображения.

Методы класса:
`saveProducts(array: IProduct[])` - сохраняет массив товаров из параметров метода.
`getProducts(): IProduct[]` - получение массива товара их модели.
`getProductById(id: string): IProduct` - получение товара по ID.
`saveProduct(currentProduct: IProduct)` - сохранение товара для подробного отображения.
`getProduct: IProduct(currentProduct)` - получение товара для подробного отображения.

#### Класс Bin
Содержит в себе товары, выбранные пользователеи для покупки.

Конструктор:
`constructor(productsForBuy: IProduct[])` - В конструкторе передается массив выбранных для покупки товаров.

Поля класса:
`productsForBuy: IProduct[]` - хранит массив товаров, выбранных покупателем для покупки.

Методы класса:
`getProductForBuy(): IProduct` - получение массива товаров, которые находятся в корзине.
`addProductForBuy(product: IProduct): void` - добавление товара, который был получен в параметре, в массив корзины.
`removeProductForBuy(product:  IProduct): void` - удаление товара, полученного в параметре из массива корзины.
`clearBin(): void` - очистка корзины.
`getBinCoast(): number` - получение стоимости всех товаров в корзине.
`getBinProductCount(): number` - получение количества товаров в корзине.
`checkProductById(id: string): boolean` - проверка наличия товара в корзине по его id, полученного в параметр метода.

#### Класс Buyer
Содержит в себе данные покупателя, необходимые для оформления заказа.

Конструктор:
`constructor()` - создаёт объект покупателя с пустыми полями.

Поля:
`customer: ICustomer` - объект с данными покупателя.

Методы:
`setPayment(type: TPayment): this` - устанавливает способ оплаты, возвращает текущий объект.
`setAddress(address: string): this` - устанавливает адрес, возвращает текущий объект.
`setPhone(phone: string): this` - устанавливает телефон, возвращает текущий объект.
`setEmail(email: string): this` - устанавливает email, возвращает текущий объект.
`getCustomer(): ICustomer` - возвращает объект с данными покупателя.
`clear(): void` - очищает все поля покупателя.
`validate(): { [key: string]: string }` - проверяет заполненность полей, возвращает объект с ошибками {поле: сообщение}.


### Класс коммуникационного слоя

#### Класс ApiClient
Назначение: обеспечивает взаимодействие с сервером через интерфейс IApi. Предоставляет методы для получения списка товаров и создания заказа.

Конструктор:
`constructor(api: IApi)` — принимает объект, реализующий интерфейс IApi для выполнения HTTP-запросов.

Поля:
`api: IApi` — объект для выполнения запросов к серверу.

Методы:
`getProducts(): Promise<IProduct[]>`
Назначение: получает список всех товаров с сервера.
Возвращает: промис с массивом объектов IProduct.
Ошибки: в случае ошибки выводит её в консоль.

`makeOrder(order: IOrder): Promise<IOrderResponse>`
Назначение: отправляет на сервер данные заказа для его создания.
Параметры:

`order: IOrder` — объект с данными заказа.
Возвращает: промис с объектом IOrderResponse, содержащим идентификатор созданного заказа и общую сумму.
Ошибки: в случае ошибки выводит её в консоль.
